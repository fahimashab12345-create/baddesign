01 // Origin

Everything runs
on my hardware.

I'm Fahim. Most of what I build starts as a tool I needed at 2am and ends up outliving the problem: a desktop environment that lives in a browser tab, a ComfyUI batch engine that never sends a prompt anywhere, a Discord bot structurally forbidden from sending a message on its own.

The through-line is local-first. If it needs a server to work, it probably didn't need to exist. The machine already has a GPU in it — that's usually enough. The other half of the work needs no GPU at all: cutting phonk edits by ear until the drop hits.

SIGNAL 03

ComfyBatch

Continuous private ComfyUI batch generation. Swap the prompt, press Start, walk away — every image carries embedded metadata, a JSON sidecar with the exact workflow, and a row in the generation log. Ships as one self-contained .exe, and an orphan-engine reaper guarantees images only run when you press the button. Under it sits roughly 100 GB of weights — IllustriousXL, PonyXL, SDXL, Krea 2, FLUX, Wan 2.2 — and about a hundred trained LoRAs, one of which is me.

SIGNAL 04

Love Language Model

Learns how one specific person actually communicates from their own messages, keeps the evidence behind every score, and drafts replies written for that person. Bipolar traits are signed and evidence decays, so it models who someone is now, not their historical average. Consent is structural: a consent record with no provenance is not a record.

  • NLP

SIGNAL 05

Roblox Security Audit

RemoteEvent:FireServer is a public, unauthenticated call — any client can invoke it with any arguments. NetGuard wraps every handler in typed validation and rate limits. Audit watches for writes only the server should make. HostileProbe fires escalation and fuzz payloads from a legitimate seat and reports exactly which ones the server accepted.
